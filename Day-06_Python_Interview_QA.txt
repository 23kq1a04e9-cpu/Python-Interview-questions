PYTHON INTERVIEW QUESTIONS — DAY 06
Level: Functions — Beginner to Intermediate

1. What is the difference between print() and return in a Python function?

Answer:
print() displays a value on the screen, while return sends a value back from the function to the caller. A returned value can be stored in a variable or used in another expression.

Example:
def add(a, b):
    print(a + b)

def multiply(a, b):
    return a * b

add(2, 3)
result = multiply(2, 3)
print(result)

Output:
5
6


2. What are default arguments in Python?

Answer:
A default argument is a parameter that has a predefined value. If the caller does not provide a value for that parameter, Python uses the default value.

Example:
def greet(name, message="Hello"):
    print(message, name)

greet("Alex")
greet("Sam", "Welcome")

Output:
Hello Alex
Welcome Sam


3. What are positional and keyword arguments in Python?

Answer:
Positional arguments are passed according to the order of the parameters, while keyword arguments are passed by explicitly specifying the parameter name.

Example:
def student(name, age):
    print(name, age)

student("Alex", 21)
student(age=22, name="Sam")

Output:
Alex 21
Sam 22


4. What is variable scope in Python?

Answer:
Variable scope defines the part of a program where a variable can be accessed. Common scopes include local scope, global scope, and enclosing scope.

Example:
x = 10

def show():
    y = 20
    print(x)
    print(y)

show()

Output:
10
20


5. What is the difference between local and global variables in Python?

Answer:
A local variable is created inside a function and can normally be accessed only within that function. A global variable is defined outside functions and can be accessed from different parts of the program.

Example:
x = 10

def show():
    y = 20
    print(x)
    print(y)

show()
print(x)

Output:
10
20
10
