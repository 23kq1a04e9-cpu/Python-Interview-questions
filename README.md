PYTHON INTERVIEW PREPARATION
============================

A daily Python interview preparation series designed to progress from
ZERO level to HIGH-level interview preparation.

GOAL
----

Practice 5 new Python interview questions every day.

Each question contains:
- Question
- Interview-ready Answer
- Example
- Expected Output (when applicable)

The difficulty will gradually increase from basic Python concepts to
advanced Python and interview-oriented coding questions.

RULES
-----

1. Exactly 5 new questions will be prepared every day.

2. Questions from previous days must not be repeated.

3. Questions will gradually increase in difficulty.

4. Answers will be short, clear, and suitable for interviews.

5. Examples will be included when they help understand the concept.

6. The preparation will move from basic concepts to intermediate,
   advanced, and high-level interview questions.

7. Coding-based and output-based questions will be introduced gradually.

8. Important Python concepts will be revised through interview questions
   without unnecessarily repeating the same questions.

PYTHON INTERVIEW QUESTIONS
==========================

Day 01 — Python Basics
----------------------
1. What is Python?
2. Why is Python popular?
3. What is a variable in Python?
4. What are the common built-in data types in Python?
5. What is the difference between = and == in Python?

Day 02 — Python Basics
----------------------
6. What is dynamic typing in Python?
7. What is the difference between int, float, and str in Python?
8. What is type conversion in Python?
9. What are operators in Python?
10. What is the difference between implicit and explicit type conversion?

Day 03 — Data Structures
------------------------
11. What is the difference between a list and a tuple in Python?
12. What is a string in Python?
13. What is indexing in Python?
14. What is slicing in Python?
15. What is the difference between mutable and immutable objects in Python?

Day 04 — Beginner to Intermediate
---------------------------------
16. What is a nested list in Python?
17. How do you access elements in a nested list?
18. What is a list comprehension in Python?
19. What is the difference between append() and extend() in Python?
20. What is the difference between == and is in Python?

**Day 05 — Intermediate Basics** 
--------------------------------
21. What is the difference between sort() and sorted() in Python?
22. What is a function in Python?
23. What is the enumerate() function in Python?
24. What are function parameters and arguments in Python?
25. What is the difference between pass, break, and continue in Python?
## Day 06 — Functions
----------------------
26. What is the difference between print() and return in a Python function?
27. What are default arguments in Python?
28. What are positional and keyword arguments in Python?
29. What is variable scope in Python?
30. What is the difference between local and global variables in Python?
